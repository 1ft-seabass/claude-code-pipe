# 画像アップロード API（POST /images）追加 - 開発記録

**作成日**: 2026-05-24
**関連タスク**: 画像つき送信機能の基礎として、画像を一時保存できる API を追加

## 問題

将来的に「画像つきメッセージ送信」を実装するため、まず画像を tmp に置ける API が必要。最小依存（`express`, `chokidar`, `ws` のみ）の方針を維持しながら追加したい。

## 試行錯誤

### アプローチA: multipart/form-data + multer

**試したこと**: 標準的なファイルアップロード方式

**結果**: 不採用

**理由**: 新規依存（`multer`）の追加が必要。プロジェクトの「最小依存」方針と相性が悪い。

---

### アプローチB（採用）: base64 JSON

**試したこと**: JSON ボディに base64 エンコード済みデータと filename を含める

**結果**: 成功

**コード例**:
```bash
curl -X POST http://localhost:3100/images \
  -H 'Content-Type: application/json' \
  -d '{"data": "<base64>", "filename": "photo.png"}'
# → {"path": "/tmp/claude-code-pipe/<uuid>-photo.png", "filename": "<uuid>-photo.png"}
```

**採用理由**:
- 既存 API と一貫した JSON 形式
- 新規依存ゼロ（`crypto.randomUUID()` は Node 標準）
- base64 のサイズオーバーヘッド（約33%）は許容範囲

## 解決策

**実装場所**: `src/api.js`

### セキュリティ対策

1. **拡張子ホワイトリスト**: `.jpg`, `.jpeg`, `.png`, `.pdf`, `.txt`, `.md` のみ許可
2. **ファイル名サニタイズ**: `path.basename()` でパス成分除去、`[^a-zA-Z0-9._-]` を `_` に置換
3. **UUID プレフィックス**: `<uuid>-<safeName>` で衝突防止 + 推測困難化
4. **保存先固定**: `/tmp/claude-code-pipe/` のみ（projectPath 等での書き込み先指定は受け付けない）

### .gitignore について

保存先がシステムの `/tmp/` 以下のため、プロジェクトの `.gitignore` 修正は不要。

## レスポンス例

```json
{
  "path": "/tmp/claude-code-pipe/a03a3bef-433a-49d6-a54c-ec58af1ec004-test_image.png",
  "filename": "a03a3bef-433a-49d6-a54c-ec58af1ec004-test_image.png"
}
```

許可外拡張子の場合：

```json
{ "error": "File type not allowed. Allowed: .jpg, .jpeg, .png, .pdf, .txt, .md" }
```

## 学び

- **最小依存ポリシーは API 設計にも波及する**。multipart より base64 JSON を選ぶ理由になりうる
- **拡張子ホワイトリスト方式は最初に絞っておく**のが安全。後から拡張する方が、後から制限する方より楽
- **UUID プレフィックスはファイル名衝突対策と推測困難化を両立**できる軽量な手段
